# 🥘 App de Menús y Compras: Fusión España-México

## 📖 Resumen de la Aplicación (Overview)
Esta es una aplicación web interactiva diseñada a medida para gestionar la planificación de comidas quincenales de la familia. El sistema integra de manera práctica los sabores de la gastronomía española con la cocina de Jalisco, ofreciendo un equilibrio entre guisos tradicionales y alternativas más ligeras. Su propósito principal es optimizar el tiempo en la cocina mediante la técnica de *batch cooking* (preparación de bases) y eliminar el estrés de hacer la compra automatizando la lista exacta de ingredientes necesarios para el supermercado.

## ✨ Características Principales (Features)

*   **Menú Interactivo Personalizable:** Para cada comida y cena (de lunes a viernes), la aplicación permite elegir entre 3 rutas diferentes para adaptarse a las necesidades del día:
    *   *Opción A:* Clásicos de la cocina española (ej. lentejas, marmitako).
    *   *Opción B:* Platos mexicanos y de fusión (ej. enfrijoladas, tacos al horno).
    *   *Opción C:* Alternativas ligeras y bajas en calorías para cuidar la dieta.
*   **Generador de Lista de la Compra Inteligente:** Al seleccionar los platos deseados, el sistema extrae, calcula y consolida los ingredientes necesarios, generando una lista limpia y lista para llevar al súper.
*   **Diseñado para Batch Cooking:** La lista de compras siempre incluye automáticamente los ingredientes para crear los "fondos de nevera" del fin de semana (un gran sofrito base, caldo de pollo y frijoles de la olla), los cuales se ensamblan rápidamente en las recetas diarias.
*   **Sección de "Plato Libre" (Custom Add-ons):** Un módulo de texto libre que permite añadir a la lista artículos fuera del menú regular, perfecto para incluir ingredientes de repostería casera, caprichos del fin de semana o artículos de limpieza.
*   **Interfaz Mobile-Friendly:** Interfaz limpia y responsiva (HTML/CSS/JS Vanilla) pensada específicamente para ser visualizada y manipulada desde la pantalla del móvil mientras se recorren los pasillos de la tienda.

## 🚀 Cómo usar este proyecto
1. Abre el enlace de la aplicación desde el navegador.
2. Selecciona las opciones deseadas para cada comida de la semana.
3. Añade cualquier ingrediente extra en el cajón de "Plato Libre".
4. Pulsa "Generar Lista" para obtener el resumen final de la compra.
